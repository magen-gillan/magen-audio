## عن التطبيق | About

**العربية:** Magen Audio مشغل موسيقى خفيف لأجهزة Android، مبني على Phonograph Plus باستخدام Kotlin وJetpack Compose وMedia3. صُمم ليمنحك مكتبة موسيقى مرتبة وسريعة مع دعم كامل للعربية والكتابة من اليمين إلى اليسار.

**English:** Magen Audio is a lightweight Android music player based on Phonograph Plus, Kotlin, Jetpack Compose, and Media3. It keeps your library fast and organized while providing full Arabic and right-to-left support.

## المميزات | Features

- ترتيب رقمي طبيعي للأغاني: 1، 2، 3 بدلًا من 1، 10، 2.
- Natural numeric sorting: 1, 2, 3 instead of 1, 10, 2.
- أيقونات مخصصة للمجلدات من الصور التي تختارها.
- Custom folder icons using images you choose.
- عرض اسم المجلد بوضوح دون المسار أو عدد الأغاني.
- Clean folder names without paths or track counts.
- تشغيل صحيح عند فتح الأغاني من مدير الملفات.
- Correct playback when opening a song from a file manager.
- شاشة ترحيب زجاجية مخصصة مع شخصية أليشا.
- Custom glass-style welcome screen featuring Alisha.
- العربية و27 لغة أخرى مع دعم RTL.
- Arabic and 27 additional languages with RTL support.
- فحص تلقائي للمكتبة وترتيب مخصص.
- Automatic library scanning and customizable ordering.
- بدون إعلانات أو تتبع، ومفتوح المصدر.
- No ads or tracking; fully open source.
- حجم صغير يقارب 8.8 MB مع توقيع v2 وv3.
- Compact APK of about 8.8 MB with v2 and v3 signing.
